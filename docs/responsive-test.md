## 상호작용

- 전체 / Robot SW / Embedded 필터: 각각 5 / 2 / 3개 아카이브 표시. Featured FMS는 항상 표시.
- 768px 이하 각 검사 폭에서 메뉴 열기·Escape 닫기·앵커 선택 후 닫기 확인.
- 메뉴 열린 상태의 문서 가로 넘침 없음.
- JavaScript 비활성 320px: 전체 프로젝트 표시, 메뉴 접근, 상세 링크 이동 정상. JS 전용 필터 숨김.
- 모든 HTML의 로컬 이미지·CSS·JS·페이지 참조 및 앵커 ID 검사 통과.
- 브라우저 JavaScript 오류와 로컬 리소스 4xx/5xx 없음.
- `404.html` 페이지 표시 확인. 실제 GitHub Pages의 미존재 경로 응답은 배포 전이므로 검증하지 않음.
- 390px·1440px 홈, FMS·GoSung 상세 화면을 캡처해 시각 확인. 이미지 원본 비율 유지.

1440px에서 상세 페이지 전체 높이는 약 1,557–1,661px(1000px 높이 viewport 기준)로 약 두 화면에 들어간다. 모바일은 단일 열로 전환되므로 더 길어진다.

## 재현

별도 터미널에서 `python -m http.server 4173 --bind 127.0.0.1` 실행 후 Playwright를 사용할 수 있는 환경에서:

```sh
node scripts/check-browser.cjs
```

기본 브라우저는 설치된 Edge. `BROWSER_CHANNEL=chrome` 환경변수로 설치된 Chrome을 선택할 수 있다. `PORTFOLIO_URL`로 테스트 주소 변경 가능. Playwright는 테스트 환경에 설치되어 있어야 하며 제공된 Codex 번들에서는 `NODE_PATH`로 패키지 경로를 지정한다.

검사 로그·스크린샷은 `.local-preview/`에 기록하고 Git에서 제외한다. 외부 YouTube 동영상 재생, 원본 로봇/MCU의 실기 동작, 하드웨어 성능은 이 웹사이트 검사에 포함되지 않는다.
