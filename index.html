About Me

센서와 모터부터 앱과 관제 시스템까지, 연결되는 전체 흐름을 이해하려고 합니다.

센서와 모터를 제어하는 코드부터, 로봇의 데이터를 확인하고 명령을 보내는 앱까지 직접 만들어 왔습니다.

여러 장치가 연결될 때 발생하는 통신 문제, 센서 데이터 오류, 제어 불안정 등을 직접 확인하고 수정한 뒤 다시 시험하는 과정을 좋아합니다.

최근에는 단순 구현에서 끝나지 않고, 성능 측정과 개발 과정 기록을 체계화하기 위해 Git·GitHub, Jira, Confluence 기반 협업 방식도 함께 익히고 있습니다.

PROJECT 03

AIMing Project

4명

2026.07 ~ 08 · STM32H7 · FreeRTOS · DMA · OV2640

카메라 입력, 온디바이스 추론, 장치 제어를 STM32H7에서 연결한 프로젝트입니다.

My Role

보드 선정, 카메라·디스플레이·서보 연동, FreeRTOS Task 구성, DMA 기반 영상 처리 흐름을 담당했습니다.
