# 포트폴리오 이미지 교체

이 폴더에서 웹페이지에 사용하는 이미지는 모두 `.jpg`입니다. 새 이미지를 교체할 때 **실제 JPEG 파일**로 저장하고 기존 파일명 그대로 덮어쓰세요. 확장자만 바꾸면 표시되지 않습니다.

메인페이지 대표 이미지의 권장 출력 규격은 **1600 × 1200 px (4:3)**입니다. 원본이 더 작다면 무리하게 확대하지 말고 4:3 캔버스에 여백을 두세요. 상세 이미지와 프로필 사진은 원본 비율을 유지하며, 작은 글자가 있는 화면 캡처는 높은 JPEG 품질(약 95, 4:4:4)로 저장하는 편이 좋습니다.

| 프로젝트 | 메인 대표 이미지 | 상세 이미지 |
| --- | --- | --- |
| AX Multi-Robot Logistics | `fms-operation-wide.jpg` | `fms-map-robot.jpg`, `fms-featured-robots.jpg` |
| GoSung | `gosung-cover.jpg` | `gosung-sensor-fusion.jpg`, `gosung-ramp-stop.jpg` |
| AIMing Project | `aiming-cover.jpg` | `aiming-blue-noise.jpg`, `aiming-lock-on.jpg` |
| Tracking Patrol Robot | `tracking-cover.jpg` | `tracking-normal.jpg`, `tracking-danger.jpg`, `tracking-fall.jpg`, `tracking-distance-horizontal.jpg`, `tracking-distance-vertical.jpg` |
| VIP Wearable | `vip-cover.jpg` | `vip-route.jpg`, `vip-obstacle-app.jpg` |
| MPS 창고 적재 제어 | `plc-demo.jpg` | `plc-demo.jpg`, `plc-hmi.jpg` |

`portrait.jpg`는 첫 화면의 프로필 사진입니다. `fms-cover.jpg`는 현재 웹페이지에서 쓰지 않는 기존 이미지입니다. `assets/favicon.svg`는 사진이 아닌 벡터 로고이므로 별도로 유지합니다.

이미지를 교체하면 웹페이지에는 바로 반영됩니다. **다운로드용 PDF는 정적 파일**이므로 새 이미지를 반영하려면 PDF를 다시 생성해야 합니다. Tracking 상세 화면은 정상·위험·낙상과 가로·세로 자세를 각각 독립된 4:3 이미지로 표시합니다. VIP 착용 사진을 교체할 때는 얼굴을 가린 버전을 사용하세요.
