PROBLEM SOLVING

문제 해결

래더 조건 오류로 출력 코일이 계속 켜졌습니다

PROBLEM

OR와 NOT 접점의 배치가 잘못되어 차단 조건과 관계없이 출력 코일이 동작했습니다.

ACTION

자기유지와 차단 조건을 단계별로 다시 확인했습니다. 접점 순서와 분기 구조를 수정했습니다.

RESULT

수동 운전과 층별 시퀀스가 조건에 맞게 동작하는 것을 확인했습니다.

LIMITATIONS
