PROJECT OVERVIEW

목표와 구현

MPS 트레이너와 Mitsubishi PLC, HMI를 이용해 창고의 층별 적재와 비우기와 수동 개별 제어를 구성한 2인 교육 프로젝트입니다.

내가 구현한 일

  • GX Works2 래더로 층별 적재와 비우기 시퀀스와 수동 개별 제어를 공동 구현
  • GT Designer3 HMI에서 적재 상태 램프, 위치 버튼, 설비 점검과 티칭 화면 구성
  • 3층 적재 전 4층 적재 금지, 4층 비움 전 3층 비움 금지 조건 구현
  • 서보 리셋 직후 구동 오류에 대기 시간을 추가하고 OR/NOT 접점 배치 오류로 상시 도통되던 코일 수정

협업 범위

Mitsubishi PLC와 MPS 트레이너를 사용한 2인 공동 교육 프로젝트입니다. 시퀀스와 HMI를 함께 구현했습니다.

PROBLEM SOLVING

문제 해결과 결과

문제와 접근

서보 모터가 리셋 직후 간헐적으로 동작하지 않았고, 래더 OR/NOT 접점의 논리 배치 오류로 출력 코일이 상시 도통됐습니다. 서보 준비 대기 시간을 넣고 자기유지와 차단 조건을 다시 확인해 래더 접점 배치를 수정했습니다.

확인 결과와 한계

층별 적재와 비우기, 수동 버튼과 HMI 상태 표시를 교육 장비에서 확인했습니다.

교육용 MPS 트레이너에서 수행한 프로젝트입니다.
