PROJECT OVERVIEW

목표와 구현

시각장애인의 보행 보조를 목표로 Android TMAP 경로, Raspberry Pi 5의 IMU 방향 정보, 팀원의 장애물 및 보행 영역 인식 결과를 연결한 2인 프로젝트입니다. 목적지 입력, 방향 표시, 좌우 진동 안내 기능을 연동했으며 GPS와 방향 오차로 전체 보행 경로의 한계도 확인했습니다.

내가 구현한 일

  • IMU의 UART Yaw 값을 읽어 사용자 방향을 앱에 표시하고 TMAP 경로 waypoint와 비교
  • 목적지 텍스트 및 음성 입력, 취소 기능과 방향 오차 범위에 따른 직진 및 회전 판단 기능 구현
  • 팀원의 장애물 및 보행 영역 인식 결과와 진행 방향을 서로 다른 좌우 진동 패턴으로 연동
  • STM32-Raspberry Pi UART 통신 불안정으로 Raspberry Pi 직접 제어 구조로 변경하고 불량 햅틱 모듈은 DC 모터로 교체
  • BLE 연결 불안정 문제를 확인하고 Bluetooth Classic으로 변경해 자동 연결 동작 구성

PROBLEM SOLVING

문제 해결과 결과

문제와 접근

BLE 연결과 초기 UART 구성이 불안정했고, GPS 시작 위치 오차가 커 경로 안내가 빗나갔습니다. Bluetooth Classic과 Raspberry Pi 직접 제어로 하드웨어 경로를 단순화하고 방향별 진동 패턴을 구성했습니다.

확인 결과와 한계

목적지 입력, 방향 표시, 장애물 및 방향별 진동 기능을 개별적으로 연동했습니다.

GPS, IMU, 경로 오차로 실제 목적지까지의 정상 보행 안내는 확인하지 못했습니다. 경로 음성 안내와 낙상 감지는 충분히 구현과 검증하지 못해 성과에서 제외했습니다.
