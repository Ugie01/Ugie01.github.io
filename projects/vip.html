PROBLEM SOLVING

문제 해결

BLE 연결이 반복적으로 끊어졌습니다

PROBLEM

Android와 Raspberry Pi 사이의 BLE 연결이 불안정해 안내 정보 전달이 중단됐습니다.

ACTION

통신 방식을 Bluetooth Classic으로 변경했습니다. 연결 상태를 확인하며 명령을 주고받도록 구조를 단순화했습니다.

RESULT

앱과 Raspberry Pi 사이의 방향 안내 데이터 연동을 확인했습니다.

LIMITATIONS

GPS와 방향 오차로 실제 목적지까지 이어지는 전체 보행 안내는 확인하지 못했습니다.
