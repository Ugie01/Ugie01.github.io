PROBLEM SOLVING

문제 해결

로봇과 Main PC의 시간 차이로 센서 지연이 발생했습니다

PROBLEM

실환경 주행에서 LiDAR 데이터 지연으로 Nav2 센서 처리 경고가 발생했습니다.

ACTION

Main PC와 로봇의 시간을 Chrony로 동기화했습니다. 센서 수신 상태를 확인해 허용 시간을 조정했습니다.

RESULT

실로봇 주행에서 센서 데이터 수신 흐름을 다시 확인했습니다.

LIMITATIONS

현재 실환경 작업 흐름을 통합 중이며 자동 배차와 교통관리는 후속 구현 범위입니다.
