PROJECT OVERVIEW

목표와 구현

ROS 2 Jazzy 기반 이동 로봇 3대와 OMX 로봇팔을 FMS에서 관리하는 7인 팀 프로젝트입니다. 로봇과 FMS는 Zenoh, 로봇팔과 FMS는 MQTT로 통신하며, 실로봇과 시뮬레이션 모드를 분리해 동일한 작업 흐름을 적용하고 있습니다.

내가 구현한 일

  • 로봇 3대에 동일한 실행 환경을 구성하고 namespace 인자로 구분해 로컬 DDS, Zenoh Bridge, Router 연결 환경 구성
  • FMS 백엔드에서 로봇과 OMX 객체별 연결 상태 및 명령을 관리하고 실로봇과 시뮬레이션 모드 분리
  • Route Graph 경로를 Nav2 FollowWaypoints로 전달하고 주행 상태 관리, 경로 재생성, 정지 및 비상정지 기능 연동
  • Pickup, Workstation, 충전 노드별 최종 Yaw를 지정하고 일반 이동, 충전 이동, 자동 도킹 조건 분리
  • 주문, Pickup 이동, ArUco 정렬, MQTT OMX 작업 명령으로 이어지는 작업 흐름과 예외 처리 연동
  • Chrony로 Main PC와 로봇 시간을 동기화하고 LiDAR Scan 지연을 점검해 source_timeout을 0.2초에서 0.5초로 조정

PROBLEM SOLVING

문제 해결과 결과

문제와 접근

실환경에서 LiDAR Scan 지연, 특수 노드 도착 방향 오류, 일반 이동 중 불필요한 자동 도킹이 발생했습니다. Main PC 기준 Chrony 동기화와 source_timeout 조정으로 지연을 완화했습니다. 특수 노드에 고정 Yaw를 넣고, 충전 명령과 저전력 자동 복귀에만 도킹이 실행되도록 조건을 분리했습니다.

확인 결과와 한계

로봇의 작업 지점 정지 방향과 충전 조건을 명확히 하고, Pickup 도착부터 ArUco 정렬과 MQTT 로봇팔 명령까지 하나의 작업 흐름으로 연결했습니다.

실환경 작업 흐름을 통합 중인 프로젝트입니다.
