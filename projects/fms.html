PROBLEM SOLVING

문제 해결

다중 로봇 환경의 ROS 2 통신 간섭 방지

PROBLEM

여러 AMR이 동일 네트워크에서 ROS 2 통신을 사용함에 따라 로봇별 Discovery 범위와 제어 명령 전달 경로를 분리해야 했습니다.

ACTION

로봇별 DDS Discovery 범위를 제한하고, Zenoh Bridge를 활용해 필요한 Topic과 Action을 FMS로 전달하도록 통신 구조를 구성했습니다.

RESULT

로봇별 ROS 2 Topic과 Action 인터페이스를 분리해 통신 간섭 없이 FMS에서 개별 로봇을 제어 및 관제하는 구조를 적용했습니다.

TASK FLOW & DEMO

물류 작업 연동 및 통합 시연

FMS의 작업 요청에 따라 AMR 주행, ArUco 기반 정밀 위치 정렬, OMX 적재 및 하역 작업을 연동했습니다.
기능별 실행이 가능한 데모 탭을 구성하고, 실제 로봇을 활용해 물류 작업 시나리오를 검증했습니다.

  • 작업 연동: AMR 이동부터 정밀 위치 정렬, 적재, 이송, 하역까지 작업 흐름 연결
  • 시연 환경: 기능별 단독 실행 및 통합 시나리오 실행 환경 구축
  • 통합 테스트: ROS 2 주행 결과, MQTT 작업 응답 및 FMS 상태 갱신 검증

SYSTEM VALIDATION

시스템 검증과 적용 결과

AMR 4대와 OMX 4대를 연동하여 주문 접수부터 적재, 이송, 하역 및 재고 보충으로 이어지는 물류 자동화 시스템을 구축했습니다. 최종 시연에서는 FMS를 통한 로봇 주행, ArUco 기반 정밀 위치 정렬, 작업 명령 및 응답 처리 과정을 검증했습니다.

  • 배차: 판단 기준이 명확한 상황에서는 기존 규칙 기반 방식이 적합
  • 경로 생성: 경로 생성의 정확성과 처리 속도 측면에서 기존 A* 알고리즘이 적합
  • 교통 판단: 일반적인 상황은 기존 방식이 적합하며, 복잡한 예외 상황에서는 AI의 보조적 활용 가능

팀에서는 배차, 경로 생성, 교통 판단에 대해 기존 알고리즘과 AI 기반 방식을 비교하고, 처리 성능과 안정성을 중심으로 물류 환경에서의 적용 가능성을 평가했습니다.

비교 조건에서는 기존 알고리즘이 더 적합한 결과를 보였으며, AI 기반 방식의 추가적인 성능 이점은 입증되지 않았습니다.
이에 기본 운용에는 기존 알고리즘을 유지하고, 복잡한 예외 상황에서 AI를 보조적으로 활용하는 방향을 향후 과제로 설정했습니다.

LIMITATIONS

제한된 시연 환경과 알고리즘 비교 조건에서 검증했으며, 장시간 운영 안정성과 복잡한 예외 상황에서의 AI 적용 효과는 추가 검증이 필요합니다.
