PROBLEM SOLVING

문제 해결

실로봇 주행에서 LiDAR 데이터 수신이 지연됐습니다

PROBLEM

Nav2 주행 중 LiDAR Scan 지연으로 센서 처리 경고가 발생했습니다.

ACTION

Main PC와 로봇의 시간 차이를 분석하고, LiDAR 수신 상태를 확인해 source timeout을 조정했습니다.

RESULT

설정 변경 후 실장비의 센서 수신과 Nav2 주행 로그를 다시 확인했습니다.

LIMITATIONS

실장비에서 단계별 통신과 작업 연동을 확인했으며, 전체 주문의 최종 완료까지는 검증 범위를 넓히는 중입니다.
