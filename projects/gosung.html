PROJECT OVERVIEW

목표와 구현

교내 카페 주문 상황을 가정해 시험 앱, DB, ROS 2 Humble, STM32 제어부를 4륜 로봇에 연동한 프로젝트입니다. 센서 처리와 구동 제어, ROS 2 주행 기능을 구현했으며 실제 주행 시험을 통해 모터 토크와 스키드 스티어링 구조의 한계를 확인했습니다.

내가 구현한 일

  • 핀 수 제약에 따라 STM32F407을 센서부와 구동부로 분리하고 IMU, GPS 데이터를 UART로 수집 및 전달
  • 구동부에서 좌우 목표 속도를 받아 BLDC 모터 PWM을 출력하고 홀센서 인터럽트로 속도 변화 측정
  • 초음파 센서 기반 비상정지는 ROS 2 제어 경로와 분리해 구동부에서 우선 처리
  • 정지 후 홀센서 변화로 경사로 밀림 방향을 판단하고 반대 방향 PWM을 적용하는 정차 보정 로직 구현
  • Camera Calibration과 YOLOv5 ROS 2, Lakibeam 드라이버를 이용해 객체 영역 기반 LiDAR Scan 필터링 구현

SYSTEM FLOW

시스템 구조

  1. 01IMU / GPS

협업 범위

Nav2, YOLOv5 ROS 2 wrapper, Lakibeam ROS 2 Driver를 적용했습니다. 저는 STM32 센서 및 구동 제어와 Camera-LiDAR 데이터 연동을 담당했습니다. 속도 보정은 단순 PWM 증감 방식으로 구현했습니다.

PROBLEM SOLVING

문제 해결과 결과

문제와 접근

경사로 정지 후 로봇이 밀리는 문제와 4륜 스키드 스티어링의 회전 토크 부족을 확인했습니다. 홀센서 변화로 밀림 방향을 판단해 반대 방향 PWM을 적용했고, Camera-LiDAR 데이터는 좌표 변환과 시간 동기화를 적용해 연동했습니다.

확인 결과와 한계

센서부, 구동부, ROS 2 간 데이터 흐름과 경사로 정차 보정 기능을 확인했습니다. 다만 실제 환경에서 목표한 전체 배달 경로 주행은 완료하지 못했습니다.

평지에서 외력으로 밀어도 경사로로 오인식했고, 속도 측정 정확도와 PWM 보정의 정량 검증과 간헐적 급가속 문제 해결은 완료하지 못했습니다. 객체 기반 Scan 필터는 객체 검출에 지나치게 의존했습니다.
