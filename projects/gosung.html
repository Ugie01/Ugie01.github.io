확인 결과센서와 구동 연동 시험, 목표한 배달 주행은 미달

PROJECT OVERVIEW

목표와 구현

교내 카페 주문을 가정한 별도 시험 앱, DB, ROS 2 Humble과 4륜 로봇을 연결했습니다. 센서 수집과 구동부 제어는 구현했지만, 모터 토크와 마찰력과 스키드 스티어링 구조를 충분히 고려하지 못해 목표한 회전과 배달 주행은 달성하지 못했습니다.

내가 구현한 일

  • 핀 수 제약으로 STM32F407 센서 MCU와 구동 MCU를 분리하고 IMU와 GPS 데이터를 UART로 수집과 전달
  • 구동 MCU에서 좌우 목표 속도(mm/s)를 받아 BLDC 모터 PWM을 출력하고 홀센서 인터럽트로 속도 변화를 추정
  • 초음파 센서의 근접 정지 명령은 ROS 2 제어 경로와 별도로 구동 MCU에서 처리
  • 정지 뒤 홀센서 변화로 경사로 밀림 방향을 추정하고 반대 방향 PWM을 작게 가하는 정차 보정 실험
  • 카메라 보정과 YOLOv5 ROS 2와 Lakibeam 드라이버를 이용한 객체 영역 기반 LiDAR Scan 필터링 실험

협업 범위

Nav2, YOLOv5 ROS 2 wrapper와 Lakibeam ROS 2 Driver를 적용했습니다. 저는 MCU 펌웨어와 센서와 구동 연결, Camera와 LiDAR 데이터 결합 실험을 담당했습니다. 속도 보정은 단순 PWM 증감으로 PID 제어가 아닙니다.

PROBLEM SOLVING

문제 해결과 결과

문제와 접근

경사로 정지 후 로봇이 미끄러졌고, 4륜 스키드 스티어링의 회전 요구 토크를 충족하지 못했습니다. 홀센서 카운트 변화와 방향을 이용해 정지 시 반대 방향 PWM을 주는 보정을 실험했습니다. 카메라와 LiDAR 데이터도 좌표 변환해 합쳤지만 시각 동기화는 적용하지 않았습니다.

확인 결과와 한계

센서와 구동 MCU와 ROS 2 간 데이터 흐름 및 경사로 정차 보정을 시험했습니다. 그러나 전체 배달 경로 주행은 성공하지 못했습니다.

평지에서 외력으로 밀어도 경사로로 오인식했고, 속도 측정 정확도와 PWM 보정의 정량 검증과 간헐적 급가속 문제 해결은 완료하지 못했습니다. 객체 기반 Scan 필터는 객체 검출에 지나치게 의존했습니다.
