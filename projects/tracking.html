PROJECT OVERVIEW

목표와 구현

Raspberry Pi 5에서 팀원이 만든 사람 및 Pose 인식 결과를 이용해 상황을 판단하고 추적 대상을 선택해 주행 명령으로 연결한 4인 팀 프로젝트입니다. 모바일 앱의 수동 제어와 PID 게인 설정, Flask 영상 확인 기능도 구성했습니다.

내가 구현한 일

  • 팔, 어깨, 다리 Pose 각도를 이용해 위험 및 낙상 의심 상황을 판단하고 추적 대상 선택
  • Bounding Box의 위치와 크기를 이용해 목표 방향과 화면 내 거리 유지 동작 생성
  • 대상 유실 후 재등장 시 색상 히스토그램을 비교해 기존 대상 재식별 로직 적용
  • Flutter 앱에서 수동 제어와 PID 게인 설정 및 저장, Flask에서 카메라 영상 확인 기능 구성
  • STM32 펌웨어와 PID 구현 일부를 지원하며 라즈베리파이 추적 명령과 주행부 연동

PROBLEM SOLVING

문제 해결과 결과

문제와 접근

상황 판단한 사람이 화면에서 사라졌다가 다시 나타나면 다른 대상으로 인식하는 문제가 있었습니다. 판단 당시 대상의 색상 히스토그램을 저장하고 재등장 객체와 비교하는 로직을 넣었습니다.

확인 결과와 한계

Pose 판단, 대상 추적과 주행 명령 전달을 시연했습니다.

재식별은 조명과 복장 변화에 민감했습니다. 화재 감지는 시험하지 못해 범위에서 제외했고, 장시간 무인 순찰은 검증하지 않았습니다.
