PROBLEM SOLVING

문제 해결

대상이 다시 나타나면 다른 사람으로 인식했습니다

PROBLEM

추적 대상이 화면 밖으로 나갔다가 돌아오면 기존 대상을 이어서 추적하기 어려웠습니다.

ACTION

판단 당시 대상의 색상 히스토그램을 저장했습니다. 재등장한 객체와 비교해 추적 대상을 다시 선택했습니다.

RESULT

대상 재식별을 적용해 추적 시연 흐름을 이어갔습니다.

LIMITATIONS

재식별은 조명과 복장 변화에 민감해 장시간 무인 순찰까지 검증하지 못했습니다.
